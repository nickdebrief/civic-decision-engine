# CDE Platform Stage 47.1 — Authoritative Source Visual Emphasis

## Purpose

CDE Platform Stage 47.1 completes the administrator presentation introduced in
Stage 47. It makes the unique governing source immediately recognizable without
changing the source relationship or any underlying behavior.

## Presentation

The Authoritative source Published Document panel now uses:

- a restrained Primary evidence badge;
- a presentational document icon;
- a very light CDE teal surface;
- the established teal accent border;
- compact rounded corners;
- increased spacing between the heading, title, identifier, and action;
- dedicated light- and dark-mode colours.

The Published Document title, Document Identifier, and existing Open Published
Document link remain unchanged. The identifier retains its monospace treatment.

## Accessibility

The panel is labelled by its visible heading, and the decorative document icon
is hidden from assistive technology. Link keyboard focus continues to use the
existing administrative focus treatment. Light- and dark-mode foreground and
background colours exceed the WCAG AA contrast threshold for normal text.

## Governance Boundary

This stage is presentation only. It does not alter Stage 47 relationship
locking or server-side enforcement, provenance, lifecycle, Canonical Records,
Published Documents, Record–Document Associations, hashing, APIs, routes,
database structures, or public interfaces.
