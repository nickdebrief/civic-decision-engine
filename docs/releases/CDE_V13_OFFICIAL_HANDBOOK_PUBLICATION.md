# CDE v13 Documentation Milestone — Official Handbook Publication

The official **Civic Decision Engine User Handbook — Three-Volume Edition**
has been published as the authoritative handbook for the Civic Decision Engine
(CDE) software platform and the Civic Record Exchange Framework (CREF)
methodology.

The handbook is organised into three complementary volumes:

- **Volume I — Governance Principles**
- **Volume II — Platform Operations**
- **Volume III — Investigator Guide**

Official DOI:

https://doi.org/10.5281/zenodo.21672656

This is a documentation milestone only. No platform functionality, application
code, APIs, schemas, routes, workflows, tests, governance principles, CREF
methodology, or CDE Platform behaviour changed.
